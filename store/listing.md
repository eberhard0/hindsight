## Full description (≤ 4000)

Hindsight answers one question: when did I last do that?

Log recurring life things — haircuts, gas fill-ups, oil changes, AC filter cleanings, watering the plants — with one tap. Hindsight shows how many days it's been, your full history with the gaps between each time, and your real average cadence ("30 logs · averages every 66 days").

ONE-TAP LOGGING
Type a name once. After that, "Log again" stamps the current date and time.

HISTORY THAT ADDS UP
Every occurrence is kept, newest first, with day-gap badges so you can see your rhythm at a glance.

FIX IT LATER
Forgot to log? Backdate an entry. Want context? Add a note — price, place, odometer reading.

OPTIONAL REMINDERS
Repeat every N days, weeks or months, or set a one-off target date. Due-soon and overdue things stand out on the list and can notify you.

YOUR DATA STAYS YOURS
Everything lives on your phone. No account, no ads, no analytics, no tracking. If you self-host the free open-source Hindsight server, you can sync with it — but that's entirely optional and entirely under your control.

IMPORT & EXPORT
CSV import and export round-trips the export format of the classic Hindsight app, so you can bring your history with you.

Light and dark theme. Open source: github.com/eberhard0/hindsight

## Release checklist

1. Play Console → Create app → name *Hindsight*, App, Free, accept declarations.
2. Fill the sections above (Store listing, Privacy policy, App access, Ads, Content rating, Target audience, Data safety).
3. Play App Signing is on by default — keep it. The key in `~/hindsight-keys/` is your **upload key**.
4. Testing → Closed testing → create a track, upload the `.aab` from the GitHub Release, add a tester list (email addresses — 12 needed for a personal account).
5. Testers install via the opt-in link; keep the test running **14 days**.
6. Apply for production access in the console, then Production → create release → same `.aab` (or a newer tag) → roll out.
